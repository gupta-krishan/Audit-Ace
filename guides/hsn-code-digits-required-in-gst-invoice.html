HSN Code on a GST Invoice: How Many Digits and How to Choose

Short answer: businesses with annual turnover up to ₹5 crore generally need a 4-digit HSN code on B2B invoices, and those above ₹5 crore need at least 6 digits on all invoices.

Digits required

Annual turnoverHSN digits
Up to ₹5 crore4 digits on B2B invoices; optional for B2C
Above ₹5 croreAt least 6 digits on all invoices

Many businesses use the full 8-digit tariff code anyway, which is always acceptable.

How to choose the right HSN code

  1. Write down exactly what the product is: material, type, who it is for, and how it is made.
  2. Find the matching chapter and heading (the first 4 digits) in the tariff.
  3. Pick the sub-heading that fits your product, not the closest approximate one.
  4. Confirm the code on the official GST portal's HSN search.
  5. Save the confirmed code against the item and reuse it every time.

Common mistakes

  • Using one code for products of different material, such as knitted and woven garments.
  • Copying a code from a competitor without checking the product.
  • Using a service code (SAC) for goods, or the reverse.
